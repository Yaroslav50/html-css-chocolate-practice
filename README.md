Стилізація секції Reviews та Footer Технічне завдання: Для оформлення
використовуються селектори класу В стилях відсутній !important Інтерактивні
елементи (кнопки і посилання), при наведенні мишкою або фокусі з клавіатури,
мають активний стан, вказаний в Style guide Для елемента <body> задані
властивості: font-family з домінантним шрифтом на макеті, альтернативний
варіанти сімейства шрифта (без зарубок) color з домінантним на макеті кольором
тексту background-color для всієї сторінки Розмір шрифту (властивість font-size)
точно відповідає значенням з макета Висота рядка (властивість line-height)
задана як множник Колір (властивості color та background-color) точно відповідає
значенням з макета Вага шрифту (властивість font-weight) всіх текстових
елементів точно відповідає значенням з макета. Вага шрифту явно вказана тільки,
якщо значення в макеті відрізняється від стандартного для цього елемента в
браузері Кнопкам задана властивість cursor зі значенням pointer У стилях не
повторюються значення властивостей, які задані браузером за замовчуванням.
Наприклад, посиланням не потрібно вказувати cursor: pointer, а абзацам
font-style: normal або font-weight: 400 Прихований заголовок <h2> "Our benefits"
не стилізований. Його має бути видно. Приховування цього заголовка буде в HW-3.
